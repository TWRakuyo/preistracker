Preise auf der Seite speichern (GitHub-Token)

Damit die Seite eingetragene Preise in dein Repository schreiben darf, brauchst du einmal pro Gerät einen Token. Er wird nur in diesem Browser gespeichert. Erstellen: GitHub, Settings, Developer settings, Personal access tokens, Fine-grained tokens. Nur das Repository „preistracker“ auswählen, Berechtigung „Contents: Read and write“.
